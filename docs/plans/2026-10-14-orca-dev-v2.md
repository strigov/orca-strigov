# orca-dev v2 (orca-dev-lite) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use dev-orchestrator to implement this plan phase-by-phase. Steps inside each phase use checkbox (`- [ ]`) syntax for tracking.

---

## Goal

Plugin 1.1.0 duplicates Orca's worker lifecycle with its own state machine, receipts, ledgers and hooks, and every check can stall in `HOLD`; even simple tasks break (Bureau: an hour in C6 `HOLD H1`, 224 artifact files, briefs sent with unfilled `<…>`). The approved spec `docs/specs/2026-10-14-orca-dev-v2-design.md` replaces it with plugin 2.0.0: a thin layer over native `orca orchestration` and the native `orchestration`/`orca-cli` skills, consisting of one skill (`skills/orca-dev`: pipeline, rules, caps, roles, launch recipes, 11 briefs) and two cross-platform Python files (`bin/orca_dev.py`, `install.py`).

This plan builds the new pieces additively first (Ф1 helper, Ф2 installer, Ф3 launch doc and briefs, each with unit tests in the single file `tests/test_orca_dev.py`), then switches the plugin over in one cutover phase (Ф4) that rewrites the skill entry points and docs and deletes every v1 file the spec marks `del`. Live Orca smoke runs need a running Orca, logged-in agents and the user's «ок», so they are a manual checklist after the plan (see `## Test strategy`), not a phase.

## Acceptance criteria

1. `python3 -m unittest discover tests` and `python3.13 -m unittest discover tests` both end with `Ran 64 tests` and `OK`, with `tests/test_orca_dev.py` as the only file in `tests/` and no Orca, network or real home directory used.
2. The tree matches the spec's keep/del table: `LayoutTests` passes (only `bin/orca_dev.py` in `bin/`, only `skills/orca-dev` with `SKILL.md`, `launch.md`, `roles.md`, `prompts/` holding exactly the 11 briefs, no `hooks/`, `bin/lib`, `contracts/`, vendored skills, `.sh`/`.ps1` files, release scripts, `.github/`, `spikes/` or old `docs/*`), while `docs/specs/2026-10-14-orca-dev-v2-design.md`, this plan, its ledger and `docs/reviews/orca-dev-v2-*` records still exist.
3. All three manifests report `orca-strigov` `2.0.0` with one shared description and no `hooks` key; `.codex-plugin/plugin.json` keeps `"skills": "./skills/"`.
4. Every brief lints clean (`<UPPER_SNAKE>` only), is at most 2 KiB, declares exactly the tokens of the Contracts table and fills by bare name through `orca_dev.py brief --dry-run`; `launch.md` (at most 8 KiB) repeats the helper's argv, markers, timeouts, modal rows and exit codes, which `LaunchDocTests` checks.
5. `SKILL.md` (at most 18 KiB) and `roles.md` (at most 5 KiB) contain the pipeline, rules, caps, failures, resume algorithm and role table anchors that `LayoutTests` checks, and no file under `skills/orca-dev` contains `HOLD` or `UNVERIFIABLE`; `README.md` and `README.ru.md` are at most 80 lines with the 5-step install, `AGENTS.md` at most 30 lines.
6. The post-plan smoke checklist below is executed by the user (or the implementing session together with the user) and its results, including the line «Windows: юнит-тесты и smoke не прогнаны» when no Windows machine is available, are reported in a message to the user. This criterion closes the live part of spec AC14; it is not a completion gate for dev-orchestrator.

## Non-goals / deferred

- Parallel phases in worktrees, the `chatgpt-web/pro` bridge, planning profiles, gate/synthesizer/diagnosis/quickfix/integration-check roles (spec "Вне скоупа").
- Marketplace publishing, release scripts, CI workflows: deleted, not replaced.
- Automatic deletion of Codex plugin caches, stale skill copies or `.superpowers/` (install.py and the coordinator only list and ask).
- Bureau migration (spec "Переход Bureau"): a separate step after installation, not in this plan.
- Running live Orca smoke runs inside any phase.
- Windows fixes beyond the shared Python code and unit tests (for example a possible newline problem in Orca's Windows `.cmd` shim): found problems are reported, not fixed here.
- Handling more modals than the four rows of the table (for example `codex-model-migration-prompt`): they end in exit code 5 by design.
- Ledgers, receipts, hashes, state files or any state machine.
- Auto-activation of `orca-dev` without an explicit `$orca-dev` / `/orca-strigov:orca-dev`.
- An `orca repo add` check in `install.py` (the smoke checklist adds the toy repo by hand).
- Listing `~/plugins/orca-strigov` (the personal-marketplace source copy) as a stale copy: deleting it would break the Codex registration; README step 4 refreshes it.

## Contracts

### `bin/orca_dev.py` command line

| subcommand | arguments | stdout | exit codes |
|---|---|---|---|
| `brief` | `<template> [KEY=VALUE ...] [--set-file KEY=PATH ...] --title T [--run ID] [--dry-run]`; `<template>` is an existing file path or a bare name resolved to `skills/orca-dev/prompts/<name>.md` (`.md` optional); arguments may be intermixed | the `task_id`; with `--dry-run` the filled text, byte-exact (CRLF and UTF-8 kept, a leading BOM of a `--set-file` file dropped) | 0 ok; 1 the template has an angle token that is not `<UPPER_SNAKE>`, or a template token got no value (stderr lists them; Orca is not called); 2 usage, malformed/duplicate/unknown KEY, unreadable or non-UTF-8 file, template not found; 3 `task-create` failed |
| `ready` | `<handle> <agy\|codex\|claude\|marker> [timeout-s]` (non-negative integer, default 120) | `{"dismissed": [...]}` on 0; otherwise the error and the last 15 screen lines on stderr | 0 ready; 1 timeout; 2 usage; 3 five failed `terminal read` in a row; 5 unknown modal, refused `terminal send`, or a known modal still shown after 3 dismissals; 6 login screen |
| `spawn` | `--agent agy\|codex\|claude --model M [--effort E] --title T --task TASK_ID [--worktree active]`; `--effort` forbidden for agy, required otherwise | exactly one JSON line, also on failure: `{"stage", "handle", "task_id", "dispatch_id", "request_id", "dismissed", "agent", "screen", "error"}`; `stage` ∈ `null` (usage), `terminal_create`, `ready`, `dispatch`, `done`; unknown values `null` / `[]` | 0 done; 1 agent not ready (`ready` 1 or 3); 2 usage (no Orca call); 3 `terminal create` failed; 4 `dispatch` failed or unknown (`handle`, `request_id` set); 5 unknown modal (`screen` set); 6 login screen (`agent` set) |
| `close` | `<handle>` | `{"handle", "closed", "evidence", "error"}`, `evidence` ∈ `"ptyKilled"`, `"absent"`, `null` | 0 confirmed; 1 not confirmed; 2 usage |

No subcommand writes a file. Any other first argument prints the usage paragraph of the module docstring to stderr and exits 2.

### Orca calls made by the helper (Orca 1.4.224, JSON paths read from its CLI bundle)

- `brief`: `orca orchestration task-create --spec <text> --task-title <T> [--run <ID>] --json` → `result.task.id`.
- `spawn`: `orca terminal create --worktree <active> --title <T> --command <cmd> --json` → `result.terminal.handle`; `orca terminal wait --terminal <h> --for tui-idle --timeout-ms 180000 --json` → `result.wait.blockedReason`; then `ready`; `orca orchestration dispatch --task <id> --to <h> --inject --retry-request <uuid4> --json` → `result.dispatch.id` (`--retry-request` must be a UUID).
- `ready`: `orca terminal read --terminal <h> --screen --limit 80 --json`, on failure the same without `--screen` → `result.terminal.tail[]`, `result.terminal.source` (`screen` means the whole frame counts; otherwise only the last 25 lines, the busy marker the last 20); between polls `orca terminal wait --terminal <h> --for tui-idle --timeout-ms 2000 --json` → `result.wait.blockedReason`; modal keys `orca terminal send --terminal <h> --text <k> --json` and `orca terminal send --terminal <h> --enter --json` (one call per step) → `result.send.accepted`; when ready, `orca terminal wait --terminal <h> --for tui-idle --timeout-ms 60000 --json` → `result.wait.blockedReason`, which goes through the same modal handling before success.
- `close`: `orca terminal close --terminal <h> --json` → `result.close.ptyKilled`; if not `true`, `orca terminal list --worktree current --json` → `result.terminals[].handle`, `result.truncated`.
- Error envelope `{"ok": false, "error": {"code", "message", "data"}}` on stdout: `error.message` becomes the `error` text; without it the last 500 characters of output.

### Agent and modal tables (`AGENTS`, `MODALS` in `bin/orca_dev.py`; mirrored in `launch.md`)

| agent | marker | busy | login screen | login after | timeout |
|---|---|---|---|---|---|
| `agy` | `Antigravity` | `not signed in` | `Select login method` | 20 s | 180 s |
| `codex` | `Ask Codex` | `Starting MCP servers` | `Sign in with ChatGPT` | 0 s | 120 s |
| `claude` | `Claude Code` | none | `/login` | 0 s | 90 s |

| modal id | agent | screen markers (case-insensitive) | `blockedReason` tokens | keys |
|---|---|---|---|---|
| `codex-update-prompt` | codex | `update available` | `codex-update-prompt`, `agent-update-prompt` | `2`, then Enter |
| `codex-hooks-review-prompt` | codex | `hooks need review` | `codex-hooks-review-prompt`, `agent-hooks-review-prompt` | `2`, then Enter |
| `claude-trust-folder` | claude | `trust this folder`, `trust the files in this folder` | `agent-trust-workspace`, `codex-trust-workspace` | Enter |
| `agy-trust-folder` | agy | `trust this folder` | `agent-trust-workspace`, `codex-trust-workspace` | Enter |

Classification order in `classify`: login screen (before `login after` it counts as busy) → known modal (screen marker or `blockedReason`) → any other `blockedReason` = `blocked` → marker present and busy marker absent = `ready` → busy marker = `busy` → otherwise `waiting`. An agent name that is not in `AGENTS` is a literal, case-sensitive marker.

Values (filled by the coordinator, documented in `SKILL.md`): `REPO` absolute repo root; `SPEC`, `PLAN` absolute paths; `TASK` task text or phase id, title and body; `VERIFY` commands, one per line; `CONTEXT` `—` or the escalation/replacement/resume line; `FINDINGS` open findings or red output; `CRITERIA` phase criteria (quick path: task text); `DIFF` git commands showing the change. Briefs contain no other `<…>` (illustrative placeholders use `{…}`), no `orchestration send`/`orchestration ask` command lines.

Worker reports (the `worker_done` the native preamble provides): writers and implementers subject `DONE` or `BLOCKED` (implementers `BLOCKED: complexity` / `BLOCKED: requirements`); reviewers subject `PASS` or `FINDINGS`, body one finding per line `{id} blocking|minor {location} — {problem} → {fix}` with id prefixes `S` (spec review), `P` (plan review), `R` (criteria review), `Q` (quality review), `I` (final-review integration); the final review body is a table `| AC{n} | closed | … |` / `| AC{n} | not closed | … |`.

## Test strategy

- Unit tests only, all in `tests/test_orca_dev.py`, stdlib `unittest`, no Orca, no network, no real home: Orca is replaced by `FakeOrca` (prefix-matched scripted responses; unscripted `terminal wait`/`terminal send` succeed), time by `Clock`, the home directory by a temp dir, external commands by `FakeRun`, `which` by lambdas.
- Ф1: brief contract (lint, unfilled, literal fill including HTML/JSX-like values, `--set-file` multi-line UTF-8 with CRLF and BOM, unknown/duplicate/malformed keys, no `task-create` on any non-zero code, byte-exact CLI `--dry-run`); `classify` as a pure function (busy/ready, agy keyring race, stream scrollback, literal marker, modals by screen and by `blockedReason`, login screens, unknown `blockedReason`); `ready` loop (busy→ready with final idle wait, timeout, stream fallback, five failed reads, usage); `spawn` (argv equals the launch.md lines, POSIX/Windows `--command`, update modal dismissed, `blockedReason` from the first wait, unknown `blockedReason` on the final wait = 5 without dispatch, codes 1/2/3/4/5/6 with the JSON fields the spec names); `close` (`ptyKilled`, absent, still listed, truncated); no files created in the working directory.
- Ф2: missing native skills (command printed, exit 1, nothing written), vendored copy is not native, clean environment exit 0, update notices never update, agy on Windows is INFO, repo + worktree trust preserving other keys and idempotent, `--check` writes nothing, missing/invalid trust files are warned and not created, Windows key spellings, stale copies listed and never deleted (incl. `+codex.<stamp>` cache versions), usage exit 2.
- Ф3: every brief lints, fits 2 KiB, has exactly its tokens, fills by bare name, contains the report words; `launch.md` repeats `build_argv`, `AGENTS`, `MODALS`, recipes and exit codes 0–6 and keeps the Windows section within 10 lines.
- Ф4: layout and deletions, manifests, size limits, no `HOLD`/`UNVERIFIABLE`, `SKILL.md`/`roles.md`/README/AGENTS anchors.
- Not tested by units: coordinator behaviour (it is prose for a model), real Orca envelopes, real agent screens and modal keys, Windows runtime. These are the post-plan smoke run.
- Verification gate command for Ф1–Ф3: `python3 -m unittest discover -s tests -p 'test_orca_dev.py'`; failures of the v1 suite (`tests/test_*.py` other than `test_orca_dev.py`) are inherited from the base commit. From Ф4 on: `python3 -m unittest discover tests`.
- Every phase runs the new file on both interpreters: `python3 -m unittest discover -s tests -p 'test_orca_dev.py' -v` (Ф1–Ф3; the old v1 suite already fails at baseline and is not a gate) and plain `python3 -m unittest discover tests` in Ф4 after the old tests are gone; the same with `python3.13`. On a machine without `python3.13` use any available 3.10+ interpreter in its place.

```python
# ---------------------------------------------------------------- orca runner

def run_orca(args: List[str], timeout: float) -> Tuple[int, Optional[dict], str]:
    """Run `orca <args>`; return (exit code, parsed stdout JSON or None, raw stdout+stderr)."""
    exe = shutil.which("orca")
    if not exe:
        return 127, None, "orca not on PATH"
    try:
        p = subprocess.run([exe, *args], capture_output=True, text=True, encoding="utf-8",
                           errors="replace", timeout=timeout)
    except subprocess.TimeoutExpired:
        return 124, None, "orca %s timed out after %ss" % (" ".join(args[:2]), int(timeout))
    except OSError as exc:
        return 126, None, str(exc)
    try:
        data = json.loads(p.stdout)
    except ValueError:
        data = None
    return p.returncode, data if isinstance(data, dict) else None, (p.stdout + p.stderr).strip()


def dig(data, *keys):
    """data[k1][k2]... or None."""
    for key in keys:
        if not isinstance(data, dict):
            return None
        data = data.get(key)
    return data


def orca_error(code: int, data: Optional[dict], text: str) -> str:
    message = dig(data, "error", "message")
    if isinstance(message, str) and message:
        return message
    return text[-500:] if text else "orca exited with code %d" % code

def lint_template(text: str) -> List[str]:
    """Angle tokens that are not <UPPER_SNAKE> (sorted, unique, with brackets)."""
    return sorted({m.group(0) for m in ANGLE.finditer(text) if not UPPER_SNAKE.fullmatch(m.group(1))})


def template_tokens(text: str) -> List[str]:
    """UPPER_SNAKE names used as <NAME> (sorted, unique)."""
    return sorted({m.group(1) for m in ANGLE.finditer(text) if UPPER_SNAKE.fullmatch(m.group(1))})


def fill_template(text: str, values: Dict[str, str]) -> Tuple[str, List[str]]:
    """One-pass literal substitution of <NAME> tokens; values are never rescanned.

    Returns (filled text, sorted names of template tokens without a value)."""
    def sub(m):
        name = m.group(1)
        if UPPER_SNAKE.fullmatch(name) and name in values:
            return values[name]
        return m.group(0)
    unfilled = [name for name in template_tokens(text) if name not in values]
    return ANGLE.sub(sub, text), unfilled


def resolve_template(arg: str) -> Path:
    path = Path(arg)
    if path.is_file():
        return path
    path = PROMPTS / (arg if arg.endswith(".md") else arg + ".md")
    if path.is_file():
        return path
    raise Usage("template not found: " + arg)


def read_utf8(path: Path) -> str:
    """UTF-8 text with a leading BOM dropped; line endings are kept byte-for-byte."""
    try:
        return path.read_bytes().decode("utf-8-sig")
    except OSError as exc:
        raise Usage("cannot read %s: %s" % (path, exc))
    except UnicodeDecodeError:
        raise Usage("not UTF-8: %s" % path)


def parse_values(pairs: List[str], set_files: List[str], allowed: List[str]) -> Dict[str, str]:
    values: Dict[str, str] = {}
    items = [(p, False) for p in pairs] + [(p, True) for p in set_files]
    for item, from_file in items:
        key, sep, value = item.partition("=")
        if not sep or not UPPER_SNAKE.fullmatch(key):
            raise Usage("expected KEY=VALUE with an UPPER_SNAKE key: " + item)
        if key in values:
            raise Usage("duplicate key: " + key)
        if key not in allowed:
            raise Usage("unknown key %s; template tokens: %s" % (key, ", ".join(allowed) or "none"))
        values[key] = read_utf8(Path(value)) if from_file else value
    return values
```

```python
def view(lines: List[str], is_screen: bool, n: int) -> str:
    """Rendered frame: the whole frame is current state. Stream: only the last n lines count."""
    return "\n".join(lines if is_screen else lines[-n:])


def classify(agent: str, lines: List[str], is_screen: bool, elapsed: float,
             blocked_reason: Optional[str] = None) -> Dict[str, Optional[str]]:
    """Pure readiness verdict: state in ready|busy|modal|needs_login|blocked|waiting, modal id or None."""
    cfg = AGENTS.get(agent)
    text25 = view(lines, is_screen, 25)
    text20 = view(lines, is_screen, 20)
    lower25 = text25.lower()
    if cfg and cfg["login"] in text25:
        return {"state": "needs_login" if elapsed >= cfg["login_after"] else "busy", "modal": None}
    for row in MODALS:
        if row["agent"] != agent:
            continue
        if any(m in lower25 for m in row["screen"]) or (blocked_reason is not None and blocked_reason in row["reasons"]):
            return {"state": "modal", "modal": row["id"]}
    if blocked_reason:
        return {"state": "blocked", "modal": None}
    marker = cfg["marker"] if cfg else agent
    busy = bool(cfg and cfg["busy"] and cfg["busy"] in text20)
    if marker in text25 and not busy:
        return {"state": "ready", "modal": None}
    return {"state": "busy" if busy else "waiting", "modal": None}


def read_screen(run: Runner, handle: str) -> Tuple[bool, List[str], bool, str]:
    """(ok, lines, is_screen, error). Rendered screen first; stream read if the host cannot render."""
    code, data, raw = run(["terminal", "read", "--terminal", handle, "--screen", "--limit", "80", "--json"], 30)
    term = dig(data, "result", "terminal")
    if code != 0 or not isinstance(term, dict):
        code, data, raw = run(["terminal", "read", "--terminal", handle, "--limit", "80", "--json"], 30)
        term = dig(data, "result", "terminal")
        if code != 0 or not isinstance(term, dict):
            return False, [], False, orca_error(code, data, raw)
    tail = [x for x in (term.get("tail") or []) if isinstance(x, str)]

def send_keys(run: Runner, handle: str, keys: List[dict]) -> bool:
    """Each step is one `terminal send` (text alone, or Enter alone). False if Orca refuses any step."""
    for key in keys:
        call = ["terminal", "send", "--terminal", handle]

            call.append("--enter")
        code, data, raw = run(call + ["--json"], 30)
        if code != 0 or dig(data, "result", "send", "accepted") is False:

    return True


def tail_text(lines: List[str]) -> str:
    return "\n".join(lines[-SCREEN_TAIL:])


def wait_ready(run: Runner, handle: str, agent: str, timeout_s: float, blocked_reason: Optional[str] = None,
               clock: Callable[[], float] = time.monotonic, sleep: Callable[[float], None] = time.sleep) -> dict:
    """Poll until the agent TUI is ready. Returns {"code", "dismissed", "screen", "error"}.

    code: 0 ready; 1 timeout; 3 five failed reads in a row; 5 unknown or undismissable modal; 6 login screen."""
    start = clock()
    dismissed: List[str] = []
    attempts: Dict[str, int] = {}
    lines: List[str] = []
    fails = 0
    error = ""

    def result(code, err=None):
        return {"code": code, "dismissed": dismissed, "screen": tail_text(lines), "error": err}

    while True:
        ok, new_lines, is_screen, error = read_screen(run, handle)
        if not ok:
            fails += 1
            if fails >= READ_FAIL_LIMIT:
                return result(3, "terminal read failing %d times: %s" % (fails, error))
        else:
            fails = 0
            lines = new_lines
            verdict = classify(agent, lines, is_screen, clock() - start, blocked_reason)
            blocked_reason = None
            state = verdict["state"]
            if state == "ready":
                data = run(["terminal", "wait", "--terminal", handle, "--for", "tui-idle", "--timeout-ms", "60000", "--json"], 90)[1]
                final = dig(data, "result", "wait", "blockedReason")
                if not (isinstance(final, str) and final):
                    return result(0)
                # The final wait saw a block: re-read and classify with it (known modal -> dismiss, login -> 6, unknown -> 5).
                blocked_reason = final
                continue
            if state == "needs_login":
                return result(6, "%s shows a login screen" % agent)
            if state == "blocked":
                return result(5, "unknown modal on %s" % handle)
            if state == "modal":
                modal = verdict["modal"]
                attempts[modal] = attempts.get(modal, 0) + 1
                if attempts[modal] > DISMISS_LIMIT:
                    return result(5, "modal %s persists after %d dismissals" % (modal, DISMISS_LIMIT))
                if not send_keys(run, handle, MODAL_BY_ID[modal]["keys"]):
                    return result(5, "orca refused terminal send for modal %s" % modal)
                if modal not in dismissed:
                    dismissed.append(modal)
        if clock() - start >= timeout_s:
            return result(1, "%s not ready on %s after %ss" % (agent, handle, int(timeout_s)))
        began = clock()
        blocked_reason = probe_blocked(run, handle)
        rest = POLL_S - (clock() - began)
        if rest > 0:
            sleep(rest)


def cmd_ready(argv: List[str], run: Runner = run_orca, clock: Callable[[], float] = time.monotonic,

    if len(argv) not in (2, 3) or not argv[0] or not argv[1]:
        print("usage: orca_dev.py ready <handle> <agy|codex|claude|marker> [timeout-s]", file=sys.stderr)
        return 2
    timeout = argv[2] if len(argv) == 3 else "120"
    if not timeout.isdigit():
        print("ready: timeout-s must be a non-negative integer, got %r" % timeout, file=sys.stderr)
        return 2

    if outcome["code"] == 0:
        print(json.dumps({"dismissed": outcome["dismissed"]}, ensure_ascii=False))
    else:
        print("ready: " + str(outcome["error"]), file=sys.stderr)
        if outcome["screen"]:
            print(outcome["screen"], file=sys.stderr)
    return outcome["code"]
```

```python
class Parser(argparse.ArgumentParser):

def run_cmd(argv: List[str], timeout: float) -> Tuple[int, str]:
    """(exit code, stdout); 127 when the program cannot start, 124 on timeout."""
    try:
        p = subprocess.run(argv, capture_output=True, text=True, encoding="utf-8", errors="replace", timeout=timeout)
    except subprocess.TimeoutExpired:
        return 124, ""
    except OSError:
        return 127, ""
    return p.returncode, p.stdout


def plugin_version() -> str:
    try:
        return str(json.loads((HERE / ".codex-plugin" / "plugin.json").read_text(encoding="utf-8"))["version"])
    except (OSError, ValueError, KeyError):
        return "?"


def is_strigov_copy(path: Path) -> bool:
    """True when the entry resolves into an orca-strigov checkout or plugin cache (a vendored copy)."""
    try:
        return "orca-strigov" in str(path.resolve())
    except OSError:

def missing_native_skills(home: Path) -> List[str]:
    missing = []
    for name in NATIVE_SKILLS:
        found = any((home / d / name / "SKILL.md").is_file() and not is_strigov_copy(home / d / name) for d in SKILL_DIRS)
        if not found:

    return missing

def stale_copies(home: Path, version: str) -> List[Path]:
    """Old orca-dev / vendored orchestration / orca-cli entries and old plugin-cache copies."""
    stale = []
    for d in SKILL_DIRS:
        for name in ("orca-dev", "orchestration", "orca-cli"):

            cached = (manifest_version(entry) or "").split("+")[0]

    return stale

    lines: List[Line] = []
    changed = False
    projects = data.get("projects")
    for path in paths:
        keys = claude_keys(path, windows)
        trusted = isinstance(projects, dict) and any(
            isinstance(projects.get(k), dict) and bool(projects[k].get("hasTrustDialogAccepted")) for k in keys)
        if trusted:
            lines.append(("OK", "claude: %s trusted" % path))
            continue
        if not write:
            lines.append(("WARN", "claude: %s not trusted -> the trust dialog will block the worker" % path))
            continue
        if not isinstance(projects, dict):
            projects = data["projects"] = {}
        entry = projects.get(keys[0])
        if not isinstance(entry, dict):
            entry = projects[keys[0]] = {}
        entry["hasTrustDialogAccepted"] = True
        changed = True
        lines.append(("OK", "claude: trust set for %s" % path))
    return changed, lines


def trust_agy(data: dict, paths: List[str], write: bool) -> Tuple[bool, List[Line]]:
    lines: List[Line] = []
    changed = False
    for path in paths:
        listed = data.get("trustedWorkspaces")
        if isinstance(listed, list) and path in listed:
            lines.append(("OK", "agy: %s trusted" % path))
            continue
        if not write:
            lines.append(("WARN", "agy: %s not trusted -> the trust dialog will block the worker" % path))
            continue
        if not isinstance(listed, list):
            listed = data["trustedWorkspaces"] = []
        listed.append(path)
        changed = True
        lines.append(("OK", "agy: trust set for %s" % path))
    return changed, lines


def update_json(file: Path, label: str, hint: str, apply: Callable[[dict], Tuple[bool, List[Line]]]) -> List[Line]:
    """Read, apply, and atomically write (temp file + os.replace) one JSON object file."""
    if not file.is_file():
        return [("WARN", "%s: %s missing -> %s" % (label, file, hint))]
    try:
        data = json.loads(file.read_text(encoding="utf-8"))
        if not isinstance(data, dict):
            raise ValueError("top-level value is not an object")
    except (OSError, ValueError) as exc:
        return [("WARN", "%s: %s is not valid JSON (%s) -> skipped, fix it by hand" % (label, file, exc))]
    changed, lines = apply(data)
    if not changed:
        return lines
    if file.is_symlink():
        return lines + [("WARN", "%s: %s is a symlink -> not rewritten, edit it by hand" % (label, file))]
    tmp = None
    try:
        fd, tmp = tempfile.mkstemp(dir=str(file.parent), prefix=".install-py.", suffix=".tmp")
        with os.fdopen(fd, "w", encoding="utf-8") as stream:
            json.dump(data, stream, indent=2, ensure_ascii=False)
        try:
            os.chmod(tmp, file.stat().st_mode & 0o777)
        except OSError:
            pass
        os.replace(tmp, file)
        tmp = None
    except OSError as exc:
        lines.append(("WARN", "%s: could not write %s (%s)" % (label, file, exc)))
    finally:
        if tmp and os.path.exists(tmp):
            os.unlink(tmp)
    return lines


def repo_paths(repos: List[Path], run: Run, git: Optional[str]) -> List[str]:
    """Each repo plus its git worktrees, resolved, without duplicates."""
    out: List[str] = []
    for repo in repos:
        candidates = [repo]
        if git:
            code, text = run([git, "-C", str(repo), "worktree", "list", "--porcelain"], 30)
            if code == 0:
                candidates += [Path(line[len("worktree "):]) for line in text.splitlines() if line.startswith("worktree ")]
        for candidate in candidates:
            if candidate.is_dir():
                path = str(candidate.resolve())
                if path not in out:
                    out.append(path)
    return out


def check_tools(run: Run, which: Callable[[str], Optional[str]], windows: bool) -> List[Line]:
    lines: List[Line] = []
    orca = which("orca")
    if orca:
        code, text = run([orca, "--version"], 30)
        lines.append(("OK", "orca %s: %s" % (text.strip() or "?", orca)))
        code, text = run([orca, "status", "--json"], 30)
        try:
            state = json.loads(text)["result"]["runtime"]["state"]
        except (ValueError, KeyError, TypeError):
            state = "unreachable"
        lines.append(("OK", "orca runtime: ready") if state == "ready" else
                     ("WARN", "orca runtime state: %s (run: orca open --json)" % state))
    else:
        lines.append(("WARN", "orca not on PATH"))
    for name in ("codex", "claude", "agy", "git"):
        exe = which(name)
        if not exe:
            if name == "agy" and windows:
                lines.append(("INFO", "agy not on PATH (native Windows): the implementer starts on its Luna fallback"))
            else:
                lines.append(("WARN", "%s not on PATH" % name))
            continue
        label = name
        if name != "git":
            code, text = run([exe, "--version"], 30)
            label += " " + (text.strip().splitlines()[0] if code == 0 and text.strip() else "?")
        lines.append(("OK", "%s: %s" % (label, exe)))
    return lines


def check_updates(run: Run, which: Callable[[str], Optional[str]]) -> List[Line]:
    """One line per outdated agent CLI with the update command; never updates anything."""
    lines: List[Line] = []
    brew = which("brew")
    if brew and run([brew, "list", "--cask", "codex"], 60)[0] == 0:
        code, text = run([brew, "outdated", "--cask", "codex"], 120)
        if "codex" in text:
            lines.append(("WARN", "codex update available -> brew upgrade --cask codex"))
    npm = which("npm")
    if npm:
        code, text = run([npm, "outdated", "-g", "--json"], 120)
        try:
            outdated = json.loads(text or "{}")
        except ValueError:
            outdated = {}
        for package in ("@openai/codex", "@anthropic-ai/claude-code"):
            if isinstance(outdated, dict) and package in outdated:
                lines.append(("WARN", "%s update available -> npm i -g %s@latest" % (package, package)))
    return lines


def emit(lines: List[Line]) -> int:
    for level, message in lines:
        print("  %-4s %s" % (level, message))
    return sum(1 for level, _ in lines if level == "WARN")


def main(argv: Optional[List[str]] = None, home: Optional[Path] = None, run: Run = run_cmd,
         which: Callable[[str], Optional[str]] = shutil.which, windows: bool = os.name == "nt",
         python: Tuple[int, ...] = tuple(sys.version_info[:3])) -> int:
    parser = Parser(prog="install.py", description=__doc__.strip().splitlines()[0])
    parser.add_argument("--repo", action="append", default=[])
    parser.add_argument("--check", action="append", default=[])
    try:
        args = parser.parse_args(argv)
        repos = []
        for raw in args.repo + args.check:
            path = Path(raw).expanduser()
            if not path.is_dir():
                raise Usage("not a directory: " + raw)
            repos.append(path.resolve())
    except Usage as exc:
        print("install.py: %s" % exc, file=sys.stderr)
        return 2
    home = home or Path.home()
    write = not args.check
    version = plugin_version()
    print("orca-strigov %s install checks (%s)" % (version, "install" if write else "check"))
    warnings = emit([("INFO", "python %s at %s (orca-strigov targets Python 3.10+)" % (".".join(map(str, python)), sys.executable))])

    missing = missing_native_skills(home)
    if missing:
        emit([("WARN", "native Orca skills not installed: %s. Install them with:" % ", ".join(missing))])
        print(INSTALL_CMD)
        return 1
    warnings += emit([("OK", "native Orca skills: orchestration, orca-cli")])
    warnings += emit(check_tools(run, which, windows))
    warnings += emit(check_updates(run, which))

    if repos:
        paths = repo_paths(repos, run, which("git"))
        for path in paths:
            print("repo: %s" % path)
        warnings += emit(update_json(home / ".claude.json", "claude", "run claude once in the repo, then re-run",
                                     lambda d: trust_claude(d, paths, windows, write)))
        warnings += emit(update_json(home / ".gemini" / "antigravity-cli" / "settings.json", "agy",
                                     "run agy once, then re-run", lambda d: trust_agy(d, paths, write)))

    stale = stale_copies(home, version)
    if stale:
        warnings += emit([("WARN", "old copy: %s" % p) for p in stale])
        print("  -> %s" % STALE_HINT)
    if warnings:
        print("install.py: %d warning(s)" % warnings)
        return 1
    print("done.")
    return 0


if __name__ == "__main__":
    sys.stdout.reconfigure(encoding="utf-8")
    sys.exit(main())
```

````markdown
# orca-strigov 2.0

A thin Codex and Claude Code plugin over native [Orca](https://orca.dev) orchestration. One skill, `orca-dev`, runs spec-driven development through supervised Orca workers: spec → plan → TDD phases → double review (Opus, then Astra) → commit, with fixed model presets. No hooks, receipts or state machine: every cap or failure ends in a declared fallback or one question to you.

Design and acceptance criteria: [docs/specs/2026-10-14-orca-dev-v2-design.md](docs/specs/2026-10-14-orca-dev-v2-design.md).

## Install

Needs Orca 1.4.224+, Python 3.10+ (`python3`; Windows `py -3`), git and logged-in `codex`, `claude` and `agy`.

1. Native Orca skills: `orca skills install --skill orchestration --skill orca-cli --agent codex,claude-code`
2. The plugin: `git clone https://github.com/strigov/orca-strigov.git`
3. Checks and project trust: `python3 orca-strigov/install.py --repo /path/to/project` (Windows: `py -3 orca-strigov\install.py --repo C:\path\to\project`). It writes only `~/.claude.json` and `~/.gemini/antigravity-cli/settings.json`, deletes nothing and lists old copies.
4. Codex: ask Codex "Use plugin-creator to install the plugin from /abs/path/orca-strigov into my personal marketplace", then `codex plugin add orca-strigov@personal`; `codex plugin list` shows `2.0.0`. Start a new session.
5. Claude Code: `claude --plugin-dir /abs/path/orca-strigov`, or `/plugin install orca-strigov@<your local marketplace>`.

## Use

- Codex: `$orca-dev add a --version flag`
- Claude Code: `/orca-strigov:orca-dev add a --version flag`

Small tasks (at most 2 code files, no schema, security or public API change, merges of accepted branches) take the quick path: implementer → checks → Opus review → Astra review → commit. Everything else: spec (you answer «ок») → plan → phases → final review. To resume, name the plan or its slug.
````
